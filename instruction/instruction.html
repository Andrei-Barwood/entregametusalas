🎨 Basic Customization

1. Change Starting Money

Find this line in the game state:

JavaScript
money: 50000, // Change this number

2. Change Company Name

JavaScript
companyName: "Your Company Name",

3. Change Colors (CSS Variables)

Find :root in the <style> section (top of file):

CSS
:root {
  --primary: #6366f1; // Main purple color
  --success: #10b981; // Green for money
  --danger: #ef4444; // Red for errors
}

Use any color picker to get hex codes (#FF5733).

⚙️ Advanced Customization

Add New Product Type

Find the startProduct function and add to the products object:

JavaScript
vr: {
  name: 'VR Experience',
  cost: 35000,
  time: 25,
  income: 12000
}

Change Employee Salaries

In hireEmployee function, modify the roles object:

JavaScript
developer: {
  name: 'Developer',
  salary: 5000, // Was 3000
  hireCost: 2500,
  skill: 75
}

Add Random Events

Find the randomEvent function and add to the events array:

JavaScript
{
  text: 'Won startup competition! +$10,000',
  effect: () => game.money += 10000
}

🔧 Troubleshooting

Problem Solution
Changes not showing Press Ctrl+F5 (hard refresh) or clear browser cache
Broke the game Undo last change (Ctrl+Z). Check for missing commas or quotes
Colors look wrong Ensure hex codes start with # (e.g., #FF0000 not FF0000)
Game won't start Open browser console (F12 → Console) to see error messages
⚠️ Important: Always keep a backup of the original file before making changes!

💡 Pro Tips

Tip 1: Use VS Code with "Live Server" extension to see changes instantly without refreshing.
Tip 2: To make game easier, increase starting money to $100,000. To make harder, reduce to $25,000.
Tip 3: Search (Ctrl+F) for specific text like "Mobile App" to find it quickly in the code.
Tip 4: All text strings must be in quotes: "Text". Numbers don't need quotes: 5000.
